# Vector AI
Overview

Explain:

Vector AI is a machine learning research project exploring neural data compression through autoencoders, latent representations, and representation learning.

Goals
## Goals

- Explore neural compression techniques
- Learn representation learning
- Study latent space geometry
- Compare compression performance
- Build a framework for ML experimentation
Features

Current features:

## Features

- Autoencoder implementation
- Latent space visualization
- Denoising autoencoder
- Experiment tracking
- Reconstruction analysis
